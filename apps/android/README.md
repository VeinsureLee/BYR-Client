# Android 客户端

**选型已确定：Gio。** 生产模块位于 `app/`，复用仓库共享的 `core/`；`probes/gio/`
保留为独立技术探针，不参与正式构建。

## 生产模块（app/）

Gio v0.10.3，包名 `cn.byr.bbs.byrclient`，ARM64，min SDK 24 / target SDK 34。
targetSdk 暂为 34，因为 Gio 0.10.3 只实现旧版返回回调；更高 targetSdk 在 Android 15+
可能启用 predictive back，导致系统直接结束 Activity、应用内返回失效。
当前功能：

- 登录、会话恢复与退出；退出或重启后回到登录页，令牌保存在应用私有目录（0600）。
- 登录后默认进入搜索页（默认 AI 搜索，可切换全站搜索）。底部导航只有五个位置：
  搜索、分区、发帖（中间主按钮）、消息、我的。
- 分区页顶部固定三个入口：全部分区、收藏版面、时间线。进入“分区”标签时默认显示
  **收藏版面**；“全部分区”列出所有分区，点击分区再进入子分区/版面。分区页标题显示
  本分区所有版面合计的今日主题、今日发帖和在线人数。版面页显示主题列表与分页，置顶
  主题默认折叠成一组，可展开查看。
- 搜索页默认进入 AI 搜索，可切换到全站搜索。全站搜索通过共享
  `application.App.Search` 调用官方 JSON 接口，按主题标题返回分页结果并可直接打开帖子；AI 搜索
  需要额外模型服务，当前明确显示为未配置，不会发起请求。
- 主题阅读：真实论坛头像、楼层正文、论坛 GIF 表情、点赞/点踩、文章收藏、回复主题/楼层、
  复制正文、查看投票/竞猜。点击楼层头像或作者名进入用户资料；置顶楼层默认折叠，可展开。
- 发帖：从导航中间按钮进入，版面通过“选择版面”逐级选择分区/子分区/版面；支持匿名、
  签名、邮件提醒、允许转出；返回、切换页签或关闭时保存草稿；失败后可再次提交。
- 时间线（全部帖子按发帖时间倒序）与分页。
- 收藏（“我的”页）：版面收藏；收藏版面会补充实时今日主题/发帖/在线统计；文章收藏
  整卡可点、可取消，支持分页。
- 消息：私信联系人与会话、收件箱/发件箱、写信/回复/转发/删除、回复与 @ 提醒。
  点击联系人进入会话，点击会话头像或名字进入用户资料。
- 我的：资料与头像、发私信、加入黑名单、完整阅读历史、设置（浅色/深色、字号、IPv6）、
  黑名单、投票与竞猜读取/提交。
- 系统返回：内页返回上一页；在分区/消息/我的等根页返回搜索页；搜索根页第一次返回提示
  “再返回一次退出应用”，第二次才退出，避免侧滑误退。页面渲染异常会显示可恢复的错误页，
  而不是白屏；Activity 恢复时会强制重绘。

尚未接入：附件选择/上传、图片查看器与表情面板、编辑器 UBB 工具栏、分享 Intent、
真机生命周期与旋转验收。当前 APK 为 debug 签名预览。

```sh
go run ./tools/dev build android
```

输出 `dist/android/`：`BYR-Client-android-arm64.apk`、字体许可证与 `manifest.json`。
构建需要 `ANDROID_HOME`（SDK）、NDK 和 JDK；正式签名密钥尚未配置。

## 技术探针（probes/gio/）

离线验证中文输入、文本选择、长列表和自定义绘制，不登录、不访问论坛；继续作为
Gio 能力对照，不随生产 Android 模块发布。

```sh
go run ./tools/dev check --scope gio-probe
go run ./tools/dev build android-probe --framework gio
```

技术探针输出在 `dist/evaluation/android/gio/`，包名与正式客户端分开。

参见 [选型比较](../../docs/android-options.md)、[验证与实机检查表](../../docs/android-evaluation.md)。
