# Android 客户端与 Gio 验证

## 生产预览（apps/android/app/）

Gio v0.10.3 生产预览模块已建立，复用共享核心，当前覆盖登录、分区/版面/主题阅读、
时间线、收藏、发帖/回复/编辑（基础）、点赞踩/收藏、个人资料和搜索占位。产物为
`dist/android/BYR-Client-android-arm64.apk`，包名 `cn.byr.bbs.byrclient`，debug 签名，
min SDK 24 / target SDK 36。

尚未覆盖：站内信/私信、投票、竞猜、网络图片与附件、文件选择、分享 Intent、深色主题、
真机输入法与系统返回验收。构建清单明确标记 `deviceTested: false`，不能视为实机通过。

## 技术探针

位置：`apps/android/probes/gio/`，Gio 与 gogio 均固定为 v0.10.3。
模块直接引用仓库的 `core/`，没有复制一套 Go 业务代码，也不引用 MyGo。

- 离线中文编辑区域，用于检查输入法、换行与光标行为。
- 可选择文本，用于检查选择和复制；手机上的长按、选区手柄、菜单需要实测。
- 按需布局的 2000 段离线文本，验证列表重排与滚动基础。
- 可切换状态的自定义绘制区域。
- 嵌入 Noto Sans SC 字体和完整 OFL 许可证，独立于系统字体的基础中文字形测试。

探针不登录、不调用论坛接口，没有帖子页、首页、导航或功能模块。彩色绘制区域
不等于已经验证图片解码/缓存，文本长列表也不等于真实图文长帖已通过性能测试。

## 构建

配置本机 `ANDROID_HOME`（SDK）、兼容 JDK；需要 SDK 平台 36、Build Tools、NDK。
本机已在 Windows、JDK 21、NDK 28.2.13676358 环境完成构建；这不是对所有环境的保证。

```sh
go run ./tools/dev check --scope gio-probe
go run ./tools/dev build android-probe --framework gio
```

输出 `dist/evaluation/android/gio/`，包括 `BYR-Gio-Probe.apk`、校验清单和字体许可证。
包名是 `cn.byr.bbs.byr_client.gioprobe`，与正式客户端分开。当前探针为 ARM64、debug
签名、min SDK 24 / target SDK 36；正式产品的兼容范围和签名尚未决定。

已有 Android 设备连接时，可以自行安装：

```sh
adb install -r dist/evaluation/android/gio/BYR-Gio-Probe.apk
```
