# 功能迁移对照

MyGo 页面已连通，并有本地接口/交互测试；不等于真实账号线上验收。

| 原有能力 | 共享实现 | MyGo 接入 |

| 网页登录诊断、复制错误 | forum.CheckWebLogin | 登录诊断、复制按钮 |
| 根分区、子分区、全部版面、筛选 | forum Sections/Section/Board | 首页版面浏览：左侧分区树、面包屑路径，子分区版面与当前分区分组同屏显示 |
| 十大、版面推荐 | forum TopTen/Recommendations | 十大、首页推荐 |

不添加原客户端未实现的创建投票、创建竞猜等功能。

## Android

选型已确定为 Gio。生产预览模块 `apps/android/app` 复用同一份核心，已接入登录与会话
恢复、分区/版面/主题阅读、时间线、收藏、发帖/回复/编辑、点赞踩/文章收藏、真实论坛头像、
今日十大/版面推荐、搜索「敬请期待」占位、投票/竞猜、私信与站内信、提醒、用户资料、
完整阅读历史、黑名单与主题/字号/IPv6 设置。0.4.3 起登录默认进入搜索页（默认 AI 搜索，可切换全站搜索），搜索接口尚未接入；底部导航
为搜索/分区/发帖/消息/我的五个位置。分区页顶部为全部分区/收藏版面/时间线三个入口，
默认打开第一个分区（首场版面），进入分区后再选择子分区与版面，并显示本分区合计统计。置顶主题与置顶楼层默认折叠。发帖从导航主按钮进入并在编辑器内选择分区/版面。系统返回优先
返回上一页，非搜索标签根页返回搜索页；搜索根页第一次返回提示确认、第二次退出。APK 为 ARM64、debug 签名，
构建清单标记为生产预览、未实机验收。发布签名和真机兼容范围尚未确认。

尚未接入：附件选择/上传、图片查看器与表情面板、编辑器 UBB 工具栏、分享 Intent、
投票/竞猜之外的创建类流程。
`apps/android/probes/gio` 仍保留为独立技术探针，不随生产 APK 发布；两者都使用
`GOWORK=off` 与相对 `replace`，桌面工作区不混入 Gio 依赖。

## 验证与边界

- 协议合约测试逐项检查路径、HTTP 方法、认证、分页和表单；覆盖空 reid、固定收藏目录、
  空附件文章 ID、字符串/数字混合 JSON、匿名用户及集合的真实字段形状。
- 会话、草稿发布成败、磁盘失败、账号隔离、并发保存、最近历史、评价切换、消息正文有业务测试。
- MyGo 无窗口测试执行登录→分区→版面→阅读→回复→上传→发布，检查草稿不会被重新创建，
  并覆盖收藏、时间线、会话、信箱、通知、资料、设置、投票和竞猜入口；搜索页只检查
  「全站搜索 / AI 搜索 · 敬请期待」占位，不请求搜索接口。
- 可选的 BYR_CAPTURE_DIR 生成本地模拟数据的页面截图，不能视为真实论坛联调。
- Windows 原生后端已验证默认窗口中的菜单点击与页面渲染，并用已有会话验证分区、版面、
  十大、帖子、资料、收藏、搜索、信箱列表和通知等只读接口。诊断只记录字段结构与数量，
  不保存令牌、账号信息或私信正文；正常单元测试仍只使用本地服务。
- Android 生产模块的 host test/vet 通过，并生成 ARM64 APK；未连接设备，输入法、返回手势、
  生命周期、网络图片与真机性能仍待验收。
- 真实响应回归覆盖文字等级、字符串子分区引用、数组/对象两种 section 字段。
  页面区分加载、读取失败和真正的空结果，失败可重试并复制诊断信息。
- 核心加密测试验证正常解密，并拒绝密文篡改或错误的 GCM 标签。
- 真实账号写入、凭据保存/退出的完整周期、Linux/macOS 原生运行和 Android 实机阅读体验仍需实际验收。

本地测试不向线上发帖、发信、投票或下注。测试夹具只在测试文件中，不进入桌面生产数据源。
