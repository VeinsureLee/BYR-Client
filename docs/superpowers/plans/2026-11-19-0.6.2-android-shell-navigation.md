# 0.6.2 Android 壳层、导航与消息实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans (recommended) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 Android 在华为 P60/鸿蒙上的安全区适配，并重整移动端首页、横向模块切换、消息页和页面标题布局。

**Architecture:** 继续使用 Gio 的 `app.NewContext` 作为系统 inset 的唯一来源，应用层不添加设备专用固定底部 padding；通过 `app.StatusColor`/`app.NavigationColor` 统一系统栏颜色。移动导航保持五个底部入口，但明确 `PageHome` 的产品含义，在分区模块中恢复今日十大；横向模块使用一个可复用的滚动 tab 组件；消息 tab 使用清晰的四项模型和现有提醒已读 API。

**Tech Stack:** Go 1.27.4、Gio v0.10.3、Android `FrameEvent`/`Insets`、`widget.List`、现有 `Forum.Refers`/`ReadAllRefers`、headless layout tests。

## Global Constraints

- Android 包名 `cn.byr.bbs.byrclient`、minSdk 24、targetSdk 34 保持不变。
- 不在 `bottomNav` 或页面中加入固定的华为/P60 专用 padding；所有安全区必须来自 `FrameEvent.Insets`。
- 底部导航顺序由单一 descriptor 定义，避免页面自己复制导航顺序。
- 横向 tab 必须支持 320dp 宽度和 1.15 字体缩放，不依赖靠近屏幕边缘的系统返回手势。
- 当前 `PageHome`、`PageSearch`、`PageTop`、`PageMessages` 的网络 API 和 route stale 检查必须保留。
- 消息“一键已读”第一阶段只覆盖已有 `reply`/`at` 提醒 API；收件箱/发件箱全部已读需要正式服务端 endpoint，不能伪造成功。
- 不在本计划中发布版本；0.6.2 版本号在全部任务和实机验证通过后再更新。
